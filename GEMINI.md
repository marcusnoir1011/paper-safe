# Paper-Safe Project Context

## Tech Stack
- **Framework:** Next.js (App Router), TypeScript
- **Backend:** Supabase (Auth & Database)
- **Styling:** Tailwind CSS
- **State Management:** React Server Components + Client-side hooks for forms

## App Purpose (Refined)
- **Concept:** A "Digi133 Shoebox" for Japan Life.
- **Key UI:** Fast receipt logging, categorization (Tax-deductible, personal, bill), and "Paid" vs "Pending" status toggles.
- **Goal:** Clean, high-fidelity UI layouts for dashboard views and receipt-entry modals.
- 
## Coding Standards (Design Focus)
- I am the developer; provide **Layouts and Tailwind classes** only.
- Focus on **Information Hierarchy**: How to show a small 7-11 receipt scan next to a large official Pension bill.
- Visuals: Use a "Modern Ledger" look—clean lines, soft shadows, and high contrast for readability.
